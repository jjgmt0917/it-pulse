# 대화 정리 저장

1. **확인**: 사용자가 정리·저장을 직접 요청했으면 바로 3번으로 간다. 끝내는 말만 한 경우에는 "오늘 대화 정리해서 저장할까요?"라고 한 번 묻고, 답을 기다린다. 확인 없이 저장하지 않는다. 거절하면 그대로 마무리한다.
2. 이 대화에서 IT 브리핑이나 후속 질문이 없었다면 저장할 내용이 없다고 알린다.
3. **저장 경로 받기**: 대화 주제를 한 줄로 짧게 정해 실행한다.
   `node "${CLAUDE_PLUGIN_ROOT}/scripts/save-note.mjs" --title "<주제>"`
   출력된 경로가 저장 위치다 (같은 이름이 있으면 번호가 붙어 나온다).
4. **마크다운 작성 후 Write로 해당 경로에 저장**. 대화에서 실제로 다룬 내용만 쓰고 새 정보나 추측을 보태지 않는다. 대화 말투(해요체)가 아니라 간결한 노트 문체로 쓴다.

   ```
   # <주제>
   - 날짜: YYYY-MM-DD

   ## 브리핑 요약
   - 항목별 제목 · 분야 · 한 줄 요약 · HN 링크/원문 링크

   ## 질문과 답
   ### Q. <사용자 질문>
   A. <답변 요약> (근거: 기사 본문 / HN 댓글 / 일반 설명)

   ## 확인되지 않은 부분
   - 대화 중 "확인 안 됨/모름"으로 답한 내용 (없으면 이 섹션 생략)
   ```
5. 저장 후 파일 경로를 한 줄로 알린다.
